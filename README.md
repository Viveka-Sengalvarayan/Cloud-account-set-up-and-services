# Experiment No. 1: Cloud Account Setup and Services Overview in Amazon Web Services (AWS)

## Aim
To create an Amazon Web Services (AWS) account and explore the AWS Management Console and its major cloud services.

## Objectives
After completing this experiment, students should be able to:

- Understand AWS Cloud.
- Create an AWS account.
- Sign in to the AWS Management Console.
- Identify major AWS services.
- Navigate through the AWS Dashboard.

## Introduction (Theory)

Amazon Web Services (AWS) is the world's leading cloud computing platform developed by Amazon. Instead of purchasing expensive physical servers, organizations can rent computing resources over the internet.

AWS provides more than 200 cloud services, including:

- Computing
- Storage
- Databases
- Networking
- Artificial Intelligence
- Machine Learning
- Security
- Analytics

These services follow a **Pay-as-you-go pricing model**, where users pay only for the resources they consume.

## Advantages of AWS

- No hardware purchase required.
- Highly scalable.
- Secure and reliable.
- Global availability.
- Cost-effective.
- Flexible resource management.

## Software Requirements

- Windows 10/11
- Google Chrome or Microsoft Edge
- Internet connection
- Email ID
- Mobile number
- Debit/Credit Card (required for AWS account verification, even for Free Tier).

## Procedure

### Step 1: Open AWS Website
Open a web browser and visit:

https://aws.amazon.com

### Step 2: Create an AWS Account
Click on **Create an AWS Account**.

### Step 3: Enter Account Details
Provide the following information:

- Email Address
- Password
- AWS Account Name

Click **Continue**.

### Step 4: Select Account Type
Choose **Personal Account**.

(Students can also select a Business Account if instructed.)

### Step 5: Enter Contact Information
Provide:

- Name
- Address
- Phone Number

Accept the agreement.

### Step 6: Payment Verification
Enter your Debit/Credit Card details for identity verification.

> Note: A small temporary verification charge may be applied and later reversed.

### Step 7: Mobile Verification
Verify your mobile number using the OTP received.

### Step 8: Select Support Plan
Choose **Basic Support (Free)**.

### Step 9: Login to AWS Console
Log in to the AWS Management Console.

The AWS Management Console dashboard will appear.

## AWS Console Overview

Students should become familiar with the following sections:

### 1. Search Bar
Used to search for AWS services quickly.

Examples:
- EC2
- S3
- Lambda

### 2. Services Menu
Contains all AWS services grouped into different categories.

**Compute**
- EC2
- Lambda
- Elastic Beanstalk

**Storage**
- S3
- EBS
- EFS

**Database**
- RDS
- DynamoDB

**Networking**
- VPC
- Route 53

**Security**
- IAM
- KMS

**Analytics**
- Athena
- EMR

**Machine Learning**
- SageMaker

### 3. Region Selection

Examples:
- Mumbai
- Singapore
- US East (N. Virginia)

Resources are created within the selected AWS Region.

### 4. Billing Dashboard

Displays:
- Usage
- Estimated Cost
- Free Tier Usage

### 5. Account Settings

Contains:
- Profile
- Security Credentials
- Multi-Factor Authentication (MFA)
- Password Settings

## AWS Services to Explore

Students should open and briefly explore the following services:

| AWS Service | Description |
|---|---|
| EC2 | Provides virtual servers in the cloud. |
| S3 | Provides cloud object storage. |
| IAM | Manages users and permissions. |
| VPC | Provides a virtual private network for AWS resources. |
| RDS | Provides a managed relational database service. |
| Lambda | Runs code without managing servers. |
| CloudWatch | Provides monitoring and logging services. |
| SNS | Provides notification services. |

Students should successfully:

- Create an AWS account.

- Locate major AWS services.
- Understand the purpose of common cloud services.
- Explore the AWS Dashboard.
